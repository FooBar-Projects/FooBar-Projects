# Roadmap

FooBar Projects is a very new platform. It's still missing many features and needs a lot of testing and development. Below is a list of some of the features that are in the works, in no particular order:

- [Classroom, section, and assignment configuration options](../../issues/13). This will enable many new options, including allowing students `admin` access to their assignment repositories so that they can invite each other as collaborators.

Below is a list of some more extensive features that are planned to be implemented at a later time:

- [Better support for restricted institutional hardware](../../issues/4)
- [Multiple classrooms per organization](../../issues/16)
- [Autograding](../../issues/15)
- [GitLab support](../../issues/3)
- [Admin console web UI](../../issues/14)
